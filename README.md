# Руководство по настройке Jenkins

После успешной установки и регистрации, заходим в Jenkins через адрес http://localhost:8080. Логинимся и создаём новый item.

<img src="/Task_2/Jenkins_menu.PNG" alt="Меню Дженкинса">


Вводим имя item'а и выбираем тип _Pipeline_. В настройках item'a можно поставить галочку напротив GitHub Project. 

>Если мы хотим чтобы наша сборка запускалась ежедневно, необходимо поставить галочку _"Запускать периодически"_ и в поле указать  `0 0 * * *` или `H H * * *`

После, сохраняем наши настройки. Теперь нам необходимо загрузить groovy скрипт в наш проект. Идём обратно в настройки и в разделе Pipeline вставляем скрипт туда. Убираем галочку с _"Use Groovy Sandbox"_, чтобы увеличить наши возможности.

Сохраняемся и идём обратно, нажимаем на _"Собрать сейчас"_. Далее, если код не получилось собрать, то можно зайти в каждую сборку и посмотреть ошибку в _'Console Output'_. Необходимые нам файлы можно посмотреть в _'Workspaces'_.
